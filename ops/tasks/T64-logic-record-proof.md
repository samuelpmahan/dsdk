**Pitfalls.**
- `_check_args(store, prefix)`: `TypeError` unless `store` is a `PxC`; `TypeError` unless `prefix` is a `str`; `ValueError` unless `_PREFIX.fullmatch(prefix)` (use `fullmatch`, not `match`: a prefix ending in a newline must fail).
- `StepCalculation.__init__` just stores `rule`, `formula`, `premises` as attributes of the same names. `__call__(self, inputs)`: `cited = [inputs[f"c{j}"] for j in range(len(inputs))]`; build the mini proof `[Step(f, Rule.PREMISE, ()) for f in cited] + [Step(self.formula, self.rule, tuple(range(len(cited))))]`; `result = check(mini, list(cited) + list(self.premises))`; if `not result.ok` raise `ProofStepError(result.reason)`; else return `self.formula`. A premise step has no inputs, so its mini proof is the single step checked against the proof's premises.
- `RecordedProof.conclusion` is `self.parts[-1]`.
- `record_proof` order of work: `_check_args`; `proof` must be a `Sequence` (not a `str`/`bytes`) of `Step` (else `TypeError`); `prem = tuple(premises)` all `Formula` (else `TypeError`); an EMPTY proof returns `Judgment(Status.INVALID, None, "empty proof: there is nothing to record")` without touching the store; then `result = check(steps, prem)`. Then `with store.tick(f"proof.{prefix}") as tx:` and for each step `i`: if `not result.ok and i == result.bad_step` raise `ProofStepError(result.reason)` INSIDE the tick (this makes the tick roll back and leaves FAILED receipts for the steps already composed); otherwise `parts.append(tx.compose(f"px.{prefix}.{i}", Part(StepCalculation(step.rule, step.formula, prem)), inputs))` where `inputs = {f"c{j}": parts[c] for j, c in enumerate(step.cites)}` (the cited Parts, named c0, c1, ... in cite order, nothing else). A fresh `Part(StepCalculation(...))` per step. Wrap the `with` block in `try/except ProofStepError as exc` and return `Judgment(Status.INVALID, None, str(exc))`; the reason must equal `check`'s reason exactly. Do NOT catch other exceptions (`AddressOccupiedError`, `TickInProgressError` must propagate). On success return `Judgment(Status.KNOWN, RecordedProof(prefix, tuple(parts)), "")`.
- A step whose `cites` are out of range never reaches `compose` because `check` reports it first and the `ProofStepError` is raised at that index; so `parts[c]` is only indexed for valid cites.
- `replay_proof`: `_check_args`; collect `parts` by reading `px.<prefix>.0, 1, ...` while `store.has(...)` (use `store.get`); none -> `Judgment(Status.NOT_OBSERVED, None, f"no proof is recorded under {prefix!r}")`. For each step Part: `comp = p.composition`; `calc = comp.calculation.value if comp is not None else None`; if `calc` is not a `StepCalculation` or the input names are not exactly `c0, c1, ...` in order, return INVALID with reason `f"step {i} was not produced by a proof step"`. For each input Part find its index among the EARLIER step Parts by identity (`parts[j] is inp`, `j < i`); not found -> INVALID `f"step {i} cites a Part that is not an earlier step of this proof"`. All steps must share the same `premises` tuple (compare with `!=`) else INVALID starting `"steps disagree about the premises"`. Rebuild `Step(p.value, calc.rule, tuple(cites))`. Finally `check(steps, premises)`: valid -> `Judgment(Status.KNOWN, tuple(steps), "")`, else INVALID with `result.reason`.
- `Part.value` returns the same object for a callable (here the `StepCalculation` instance), so `comp.calculation.value` is the instance you stored. Formulas are deep-copied on each `.value` access; compare with `==`.

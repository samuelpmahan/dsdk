# T63-prob-expectation-calc

**Goal.** Make the typed Calc language load-bearing for probability: implement `_prepare`, `_value_in_world`, `expectation` and `sample_expectation` in the new module `src/dsdk/prob/expect.py`. An expectation question is a Calc expression over a belief's Boolean variables (for example `"(if P22 then 1 else 0) + (if P31 then 1 else 0)"`); it is parsed, type-checked and evaluated by `dsdk.lang` in every possible world, then averaged exactly with the belief's weights.

**Pitfalls.**
- `_prepare(belief, calc_text)` returns a triple `(expr, names, failure)` and does the first three pipeline steps in THIS order: (1) `calc.parse_calc(calc_text)` inside `try` catching `LangError`: on error return `(None, (), Judgment(Status.INVALID, None, f"unparseable expression: {exc}"))` (`str(exc)` already ends with `(at offset N)`); (2) `names = tuple(sorted(calc.free_vars(expr)))`; any name not in `belief.variables` gives `(None, names, Judgment(Status.UNKNOWN, None, "unmodelled variables: " + ", ".join(missing)))` with `missing` in sorted order; (3) `checked = calc.typecheck(expr, {v: calc.Type.BOOL for v in names})`: if its status is not KNOWN return INVALID with reason `f"ill-typed expression: {checked.reason}"` (the checker's own reason appended unchanged); if its value is not `calc.Type.INT` return INVALID with reason `f"not an integer expression: {calc.to_source(expr)} has type {checked.value.value}"`. On success return `(expr, names, None)`. The unmodelled-variable check must come BEFORE the type check (a test combines an unknown name with a type error).
- `_value_in_world(expr, names, world)`: bind ONLY the expression's free variables: `calc.evaluate(bind_assignment(expr, {v: world[v] for v in names}))`. The result must be an `int` with `type(value) is int` (a `bool` would be a bug; raise `AssertionError` otherwise). A well-typed closed term never gets stuck, so do not catch `StuckError`.
- `expectation(belief, calc_text, given_text=None)`: `TypeError` for a non-`Belief`, a non-`str` `calc_text`, or a `given_text` that is neither `None` nor `str`. Then `_prepare`; return the failure unchanged. If `given_text` is given: `parsed = parse_text(given_text, "evidence text")` (already imported from `ask.py`); return it unchanged if its status is not KNOWN; its value is a logic formula; if it mentions variables not in `belief.variables` return `Judgment(Status.UNKNOWN, None, "unmodelled variables: " + ", ".join(sorted(missing)))` (use `dsdk.logic.variables`, already imported as `logic_variables`). Then loop over `belief.worlds`: `world = w.assignment()`; skip worlds where the evidence is false (`logic_evaluate(given, world)`); `total += w.weight`; `acc += w.weight * _value_in_world(...)` only if `w.weight` is non-zero. If `total == 0` return INVALID with reason `"evidence has probability zero: the conditional expectation is undefined"` when evidence was given, else `"belief has zero total weight: no expectation is defined"`. Otherwise `Judgment(Status.KNOWN, acc / total, "")` with `Fraction` values.
- `sample_expectation(belief, calc_text, n, seed)`: `TypeError` for a non-belief or non-str text. Call `drawn = sample_worlds(belief, n, seed)` FIRST (this raises for a bad `n`/`seed` even when the belief is dead), then `_prepare` and return its failure if any, then return `drawn` unchanged if it is not KNOWN (INVALID for a dead belief), then `n == 0` gives `Judgment(Status.UNKNOWN, None, "n is 0: no draws, no estimate")`. Each draw in `drawn.value` is a tuple of `(name, bool)` pairs: use `dict(draw)` as the world. `mean = sum(values) / n` (a float); the variance is `sum((x - mean) ** 2 for x in values) / (n - 1)` when `n > 1` else `0.0`; `stderr = math.sqrt(var / n)`. Return `Judgment(Status.KNOWN, MeanEstimate(n, mean, stderr), "")`. Use the draws exactly as `sample_worlds` gives them; do not call `random` yourself.

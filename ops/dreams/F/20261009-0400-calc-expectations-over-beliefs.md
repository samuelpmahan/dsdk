# Compute expectations of Calc expressions over a belief (makes the typed language load-bearing for probability)
kind: cross-track link
idea: Add expectation(belief, calc_text): parse a Calc expression such as "(if P22 then 1 else 0) + (if P31 then 1 else 0)" with the language package, type-check it against the belief's Boolean variables (typecheck returns a Judgment), then evaluate it in every possible world with the existing bridge that binds a world as nested lets, and sum weight times value exactly. Return the expected value as an exact fraction, INVALID with the offset for text that does not parse, and a flagged type error for text that is not Int.
why it's interesting: Of the language package only the formula parser is called by anything later; the typed Calc language, its type checker, its evaluator and the bridge that binds assignments are called by nothing but their own tests. That is the thin spot in the stack. Expected pit count, expected number of safe cells, expected cost of a move are the questions the Wumpus agent and the Lost Lands instruments actually need, and the geometry track (paused) needs expectations from probability anyway.
smallest experiment: One function in dsdk.prob that does parse_calc, typecheck with every belief variable declared Bool, then for each world evaluate(bind_assignment(expr, world)) and accumulate exactly; tests that it equals a hand-computed expectation on the Wumpus knowledge base, that the linearity of expectation holds (E[a+b] = E[a] + E[b]) for random expressions, that an ill-typed expression is INVALID with the type error, and that a Bool-valued expression gives a probability equal to the existing probability function.
reuses: dsdk.lang parse_calc, typecheck, evaluate and bridge.bind_assignment; dsdk.prob Belief and exact fractions; dsdk.core Judgment.
probe: Read-only, using the real code on the Wumpus knowledge base built from the fixture's premise strings (pit prior 1/5, three models). The Calc expression "(if P22 then 1 else 0) + (if P31 then 1 else 0)" evaluated in each of the three worlds through bind_assignment and evaluate, weighted by the world weights and divided by the total, gives exactly 10/9, which equals P(P22) + P(P31) = 5/9 + 5/9. Command: parse_calc, bind_assignment and evaluate from dsdk.lang over prior_belief worlds.
score: surprise=3 cost=2 reuse=5
